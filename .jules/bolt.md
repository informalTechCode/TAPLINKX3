## 2025-05-19 - Removed `.any {}` closure in `isStreamingSite`
**Learning:** In high-frequency paths like URL interception and User-Agent checks (e.g., `isStreamingSite` called frequently during page load), using Kotlin's higher-order functions like `.any {}` on collections forces the instantiation of an `Iterator` object and allocates a lambda closure. This leads to continuous, unnecessary garbage collection churn.
**Action:** Replaced `.any {}` with a zero-allocation indexed `for` loop (`for (i in 0 until STREAMING_DOMAINS.size)`) to evaluate string matches. Always prefer indexed `for` loops in hot code paths over functional collection methods to eliminate GC overhead.
